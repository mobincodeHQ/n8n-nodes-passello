# n8n-nodes-passello

n8n nodes for [Passello](https://passellocard.com), loyalty cards that live in Apple Wallet and Google Wallet.

- **Passello**: add stamps to a card, redeem a reward, look up a card, list locations, get the numbers of a day.
- **Passello Trigger**: start a workflow when someone gets a card, a stamp is added or undone, a reward is earned or redeemed, a location goes quiet, something does not add up, or every night with the daily summary.

## Credentials

Create an API key in the Passello dashboard, under **Connectors** (Pro and Group plans), and paste it in the **Passello API** credential.
